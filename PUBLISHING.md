# Publish this portfolio with GitHub Pages

1. Sign in to GitHub as `mgracemercene`.
2. Create a **public** repository named `portfolio` (or another name you prefer).
3. Upload the contents of this folder to the repository's root. Make sure `index.html`, `styles.css`, `README.md`, and the `projects/` folder are at the top level.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. After GitHub Pages finishes deploying, the site should be available at `https://mgracemercene.github.io/portfolio/`.

If you instead name the repository `mgracemercene.github.io`, the site address will be `https://mgracemercene.github.io/`.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with the email address you want employers to use, or remove that email button.
- Add your LinkedIn profile URL.
- Review every statement for accuracy.
- Keep client names, screenshots, financial records, and other confidential information out of the public repository.
